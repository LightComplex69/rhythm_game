# rhythm_game
An unfinished attempt at creating a mania-styled rhythm game.
The game features randomly generated arrows that scroll up with the player having to use WASD or arrow keys to hit each arrow.
* intended to function with music but I did not get that far *
#
This project is something that I made during a 6-week high school internship under my first game design professor where I was challenged to make an application that functioned on android devices. While this application will run on android devices, I did not have time to include actual touch screen functionality given that I was also working on a zSpace project at the same time.
#

Application Used: Processing
